## 발견한 문제점·주의

1. DB하이텍의 조회 결과 접수번호(20260601001661)는 `[기재정정]사업보고서 (2025.12)`다(list.json으로 확인, 원본 사업보고서는 20260316001250). API는 최신 정정본 기준으로 응답한 것으로 보이며, 구현 시 원본/정정 중 어느 것을 근거로 삼을지 정책을 정하고 출처에 정정본 여부를 표시해야 한다. 삼성전자·SK하이닉스는 정정 없이 원본(2026-03)이다.
2. 재무 데이터에는 접수번호 외 원문 링크가 없으므로 DART 뷰어 링크는 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo={rcept_no}` 형식으로 만든다(링크 형식은 구현 시 열어 확인 필요).
3. 이 확인은 사업연도 2025, 연간 보고서 1회 조회다. 분기·누적(thstrm_add_amount) 기간 불일치는 분기 보고서 조회 시 별도 검증이 필요하다.
4. 3사 모두 적합하며 대체 후보는 필요하지 않다. 매출 규모 차이가 크므로(삼성전자는 DB하이텍의 약 240배) 비율 지표 비교는 무방하나 절대금액 비교는 단위 표기를 맞춰야 한다.
